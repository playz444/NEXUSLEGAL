## 2. Information We Collect
We only collect the minimum data strictly necessary to provide the Bot's features. Depending on how you and your server administrators use the Bot, we may process:

1. **Discord Account & Server Identifiers:**
   - User IDs, usernames, Guild (server) IDs, Channel IDs, and Role IDs.
   - Used to identify ticket creators, assign staff permissions, manage autoroles, track giveaways, and enforce moderation actions.
2. **Support Ticket Content & Transcripts:**
   - Messages, timestamps, and attachments sent inside active ticket channels are compiled into an HTML transcript when a ticket is closed and delivered to the server's designated transcript log channel.
3. **Moderation & Audit Data (Only When Configured by Server Admins):**
   - Warning records, timeout logs, and deleted message logs (in servers where administrators explicitly enable message logging).
   - Anti-scam filter triggers to protect servers from phishing or spam.
4. **Order, Payment & License Records:**
   - Payment confirmation screenshots submitted voluntarily by users inside tickets (processed via Optical Character Recognition solely to verify transaction details).
   - Order/installment records (amount, status, timestamps) and delivered license/client metadata where configured.
5. **Server Configuration & Feedback:**
   - Server settings (ticket categories, log channel IDs, welcome/greet channels, scheduled announcement messages, pricing lists) and voluntary 1–5 star ticket feedback ratings.

**We do NOT collect:** Passwords, private Discord Direct Messages outside of bot-initiated support/welcome flows, browsing history, IP addresses of Discord users, or payment card/bank credentials.

## 3. Legal Basis & Purpose of Processing
We process data strictly for the following purposes:
- **Service Delivery (Contractual / Functional Necessity):** Operating tickets, transcripts, giveaways, autoroles, and server utilities requested by users and server admins.
- **Security & Abuse Prevention (Legitimate Interest):** Detecting scam messages, preventing duplicate free-tier claims, and maintaining moderation audit trails.
- **Legal Compliance:** Fulfilling valid legal obligations or data deletion requests.

## 4. Data Sharing & Third-Party Processors
We **never sell, rent, trade, or monetize** your personal data. Data is only transmitted to essential infrastructure/API providers when required to perform a requested action:
- **Discord Inc. (Discord API):** Required for all bot commands, embeds, messages, and interactions.
- **OCR Processing Provider (OCR.space):** Extracts text from payment receipt images voluntarily uploaded by users for verification.
- **License Management API (KeyAuth):** Validates, generates, or resets license keys when triggered by authorized server staff.
- **Encrypted Cloud Backup Storage:** Private repository/backup storage used solely for disaster recovery of bot configurations and databases.

## 5. Data Security
We implement industry-standard technical and organizational safeguards to protect stored data, including:
- Encryption of sensitive credentials and API keys at rest (`AES`/Fernet-based encrypted storage).
- Restricted access controls limited strictly to the Bot's owner/authorized maintainers.
- Automated private backups to prevent accidental data loss.

## 6. Data Retention Policy
We retain data only for as long as necessary to fulfill the purposes outlined in this Policy:
- **Server Configurations:** Retained while the Bot remains in the server, or until deleted by a Server Administrator.
- **Ticket Transcripts & Order/License Logs:** Retained for operational and dispute-resolution purposes for up to **12 months** (or until a verified deletion request is received).
- **Moderation & Deleted Message Logs:** Retained in the server's own Discord log channels under the Server Administrator's control.
- **Temporary Cache / Scheduled Tasks:** Automatically purged once completed or expired.

- **Objection / Opt-Out:** Stop further data collection by not interacting with the Bot, or by Server Administrators removing the Bot from their server.

To exercise any of these rights, contact us using the details in **Section 9**. We will verify your Discord identity and respond to all valid requests within **30 days**.
